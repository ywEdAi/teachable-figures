# AI English Shift：学习地图与页面旅程反馈

记录日期：2026-09-20。来源：用户实际查看本地预览后的口述反馈及三张截图。

这是产品方向与待办记录，不是本轮实现结果。用户明确要求仅写入技能，应用改动当时由 Claude 进行；记录反馈的任务不要同时修改应用、发布或改变服务配置。后续明确授权的实现任务可按此参考继续。

## 保留的方向

用户认可地图的整体效果，特别是知识点逐层聚合、zoom in / zoom out、知识关系和逐步点亮。继续保留“大方向 → 概念群 → 细知识点”的语义缩放；不能退回只展示主题卡片或只缩放同一张静态图。

受众仍是想了解更多 AI 的人。地图用来探索概念、看见连接和学习积累；不要求先做项目。

## 三个页面各自负责什么

| 页面 | 用户目的 | 内容与交互 |
|---|---|---|
| Landing Page | 初次了解产品，直观看到学习路径 | 默认进入此页；嵌入可真实缩放的地图预览；美化方向总览；提供进入完整地图或课程的入口 |
| Map / Concepts | 找概念、看关系、选择下一步 | 搜索与筛选、可缩放地图、简洁的选中概念详情、相关课文/知识、Video Sensei 入口、下一步推荐 |
| Read | 深入学习当前课文 | 保留课内学习与练习；根据本课核心概念查找并推荐视频，在阅读内容旁呈现；改进已有“关联”入口及面板 |

Landing 的地图应复用同一套概念与缩放能力。它是可交互的学习路径预览，不需要把完整地图的所有工具、长详情与练习都搬到首页。

## Map 布局与内容约束

- 搜索目前在地图下方，需要滚动才能发现。移至地图上方或首屏可见的紧凑工具栏；控制高度，不要让搜索占用过多画布空间。
- 地图与右侧详情应作为整体排版，改进栏宽、对齐、间距及可用高度；用户认为当前侧栏过长、内部滚动体验不够成熟。
- 具体采用何种滚动容器、折叠或分区方式属于实现选择。目标是必要信息易见、比例协调、不出现冗长拥挤的独立滚动栏；用户没有要求固定像素尺寸。
- 详情以概念和关联知识为中心：简短介绍、精简的用途/例子、相关课文或知识、视频学习入口、下一步推荐。
- 减少文字量和重复按钮。核心解释保留，次要长说明按需展开；不要用长篇流程说明填满侧栏。
- **移除 Map 内的“用自己的话，点亮理解”练习表单。** 练习属于课程学习页面；这不等于删除已经保存的学习数据，也不等于取消逐步点亮。
- 保留下一步推荐。学习记录仍可影响地图状态，但不要把地图详情再次变成完整课程或练习台。

## 复用已有 Concepts / 关联能力

用户指出线上已存在 [Concepts 知识网络](https://www.ai-english-shift.space/#concepts)。实现时检查并整合已有能力，避免让 Map、Concepts 和 Read 中的“关联”成为三套重复导航或数据模型。

这是用户指出的现有入口，不代表本次记录已经核验线上部署状态。应保留旧链接的可达性，按实际代码决定合并/兼容方式，不直接删除页面或图谱数据。

Read 已有“关联”项。围绕它改善知识关系、课文和视频之间的导航，不再平行添加一个含义相同的入口。

## 视频推荐与 Video Sensei 交接

期望流程：

1. 从当前课文的核心概念找到相关视频。
2. 在 Read 旁边展示简短推荐及它与当前知识点的关系。
3. 用户点击后，**把当前视频的 URL 交给 Video Sensei，进入该视频的学习流程**。
4. 后续与既有账号、进展共享设计连接；只有真正接通并验证之后才标注自动同步。

用户不希望推荐卡片的主流程跳到原生 YouTube，也不希望依赖“打开通用 Video Sensei 首页 + 用户自己复制粘贴链接”的两步替代。

Video Sensei 需要提供接收视频 URL 的机制。深链接参数、接收页面或 API 都是待与另一端确认的实现选项，**本次未决定或验证具体 endpoint、参数名或登录交接协议**。不要编造已存在的接口，不把单纯打开 VS 首页写成已完成视频导入。

“嵌入播放器是否在某处继续保留”不是本次明确删除项；明确需要调整的是直接去 YouTube 的主跳转，以及缺少视频上下文的 VS 交接。

## 后续验收依据

- 首次进入到 Landing；首页地图能真实 zoom in / zoom out。
- 完整地图首屏能发现搜索，且搜索工具不会挤占过多空间。
- 概念详情简短、比例协调；Map 内没有“用自己的话，点亮理解”表单。
- 细知识点、概念群和方向总览仍然能互相缩放，点亮状态仍然聚合。
- Read 的核心概念与推荐视频有关联依据，并与已有“关联”功能衔接。
- “在原章节中理解”不会竖排挤压，箭头尺寸正常，窄栏也可用。
- 点击推荐视频能把选中的 URL 交给 VS；接收机制未就绪时如实记录依赖，不伪称完成。
- Map 与 Concepts 复用同一知识网络，已有链接和学习记录得到保留。
