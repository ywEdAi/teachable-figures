改变一个条件，看清一个机制。Change one condition. See one mechanism.

一个给 Claude Code、Codex 等 agent 用的 skill。它把一句难懂的结论变成离线的互动图：学习者先预测，再动手改变一个原因，观察读数，最后用自己的话解释。

An agent skill for Claude Code, Codex, and others. It turns a hard-to-grasp claim into an offline interactive figure: the learner predicts, changes one cause, watches the readout, then explains it in their own words.
