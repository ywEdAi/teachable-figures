03解释Explain

为什么贡献变了？Why did the contribution change?

遮罩在 softmax 之前把被禁止的分数换成负无穷。它们的指数是 0，允许的权重重新归一化，总和仍为 1。换一个 query 会改变分数，但绕不过遮罩。

每个权重乘以一个 value 向量。加权后的 value 相加，再投影回四个坐标。残差路径把输入绕过注意力直接加回来，随后是归一化和逐位置的前馈计算。

The mask replaces forbidden scores with negative infinity before softmax. Their exponentials are zero. Allowed weights renormalize to sum to one. Changing the query changes scores, but it cannot bypass the mask.

Each weight multiplies a value vector. These weighted values are added, then projected back to four coordinates. The residual path carries the input around attention. Normalization and a position-wise feed-forward calculation follow.

  1. 先看遮罩：在 softmax 之前，被禁止的分数换成负无穷。Start with the mask: before softmax, forbidden scores become negative infinity.
  2. 再看矩阵：对角线右上方全是 0，没有哪个 query 能读到后面的 key。Then the matrix: everything above the diagonal is 0, so no query reads a later key.
  3. 看流向 query 的线：剩下的权重重新归一化，加起来仍是 1；未来位置的权重正好是 0。Now the lines into the query: the remaining weights renormalize to sum to 1, and the weight on later positions is exactly 0.
  4. 看 z：每个权重乘以一个 value，加起来就是 z。Look at z: each weight multiplies a value, and the sum is z.
  5. 最后看计算阶段：残差、归一化和前馈都在注意力之后，不改变谁能读到谁。Finally the stages: residual, normalization and feed-forward come after attention and never change who can read whom.

这个例子模拟了什么What this example models

这是一个解码器式、后归一化（post-norm）的模块，只有一个注意力头。页面上的每个数都由上面的玩具参数算出。嵌入、位置向量和矩阵都是手选的：没有训练，也不预测下一个 token。关掉遮罩会让未来信息进入，破坏因果解码。

完整架构是：token 嵌入加位置信息 → 重复的注意力与前馈模块 → 词表投影和 softmax。本页只计算其中一个模块，省略了多头并行、dropout、交叉注意力和词表输出。这里简单的位置向量也不是论文中的正弦位置编码。

注意力、遮罩、残差归一化和 FFN 结构的来源：Vaswani et al., Attention Is All You Need, §3。原论文是带交叉注意力的编码器—解码器架构；这里是简化的解码器式教学模型，不是对整个模型的复现。

This is one decoder-style, post-normalization block with a single attention head. Every displayed number comes from the toy parameters above. Embeddings, position vectors and matrices are hand chosen. Nothing is trained, and no next token is predicted. Turning off the mask permits future information and breaks causal decoding.

The architecture context is token embeddings plus position information → repeated attention and feed-forward blocks → a vocabulary projection and softmax. This page calculates only one block. It omits multi-head parallelism, dropout, cross-attention and vocabulary output. Its simple position vectors are not the paper's sinusoidal encoding.

Source for attention, masking, residual normalization and FFN structure. Vaswani et al., Attention Is All You Need, §3. The original paper uses an encoder-decoder architecture with cross-attention. This toy is a reduced decoder-style teaching model, not a reproduction of that whole model.
